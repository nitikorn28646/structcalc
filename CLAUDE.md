# StructCalc — handoff for any new session / account

Thai structural-design web app (own code) + PDF reports, diff-tested against the user's third-party Excel
(`D:\001_NITIKORN WONGSRILA\011_รายการคำนวน\RC Design WSD & Steel roof Design ASD(New) ไผ่ ขอนเเก่น .xlsm`).
Rule: learn behaviour from the Excel only — never copy its layout, text, VBA. Record every diff run (see `D:\REA\CLAUDE.md`).
**Development rules for every account (read before any change): `.claude/skills/structcalc-dev/SKILL.md`** — direction, frozen formulas, test gate, hand-off.

## Working in the cloud / another machine
Repo = this folder (git). In the cloud (Linux): `cd web && npm ci && npm run dev` / `npx vite build`; node CLIs in `cli/` work.
NOT available there: Excel diff tests (`oracle/`, need Windows + Excel + the user's .xlsm, never commit that file) and rea-lab.
After changing any `engine/*` formula that is diff-tested, re-run the Excel diff on the Windows PC before trusting it.
User data lives in project files (.json from "บันทึกโครงการ"); keep job files in a `projects/` folder if wanted.

## User preferences (important)

  hip/valley/ridge/support/plate/post double (2C); tile roofs (concrete/ceramic) → แปสำเร็จรูป @0.30–0.33 m (not designed, maker's table).

## Planned: beam/column framing like the roof workflow (agreed idea 2026-10-30, not built)
User wants beams & columns designed the same way as the roof plates: draw, define types, auto-assign.
1. Floor plan board (reuse DrawBoard: STAAD grid, nodes, DXF import) per floor; floors list with storey heights.
2. Columns at nodes; beams node-to-node (main beams on columns, secondary beams on beams).
3. Loads: slab panels found from closed beam loops (thickness, finish, live per panel or global) → two-way trapezoid/triangle
   or one-way strips → equivalent UDL on beams; wall load per beam (height × wall type); beam self weight.
4. Analysis: each beam line as a continuous beam over its supports (1-D stiffness method); reactions → columns,
   secondary-beam reactions → point loads on the carrying beam.
5. Columns: axial load accumulated floor by floor (+ self weight), min. eccentricity moments.
6. Types: beam types B1, B2… (b×h, top/bottom bars, stirrups) and column types C1, C2… (b×h, bars, ties);
   per member a type or auto = lightest passing type; checks reuse the diff-tested WSD engines (engine/beam.js, column.js).
7. Output: plan coloured by type with tags, type schedule, report with the governing member per type, DXF.
Phasing: P1 one floor + loads + continuous-beam analysis + beam types; P2 columns + multi-floor; P3 report/DXF.
