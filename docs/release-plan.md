# StructCalc — แผนตรวจสอบก่อนใช้งานจริง (release audit)

เป้าหมาย: ใช้ทำรายการคำนวณบ้าน / อาคาร คสล. 1–3 ชั้นจริงได้ โดยผลคำนวณถูกต้องตรวจสอบได้ ใช้งานไม่หลง ข้อมูลไม่หาย
สถานะเริ่มต้น (2026-11-02, main 45a62a4): engine ทดสอบแบบสูตรปิด + Excel + PyNite แล้ว แต่ UI ทดสอบด้วยมือ
และมีแค่ตัวอย่างบ้านยโสธรหลังเดียว

## เกณฑ์ "พร้อมใช้งานจริง"
1. ชุดทดสอบอัตโนมัติทั้งหมดผ่าน (engine + E2E หน้าเว็บ) และไม่มี error ใน console
2. ทุกตัวเลขในรายการคำนวณตรงกับผลของ engine (ตรวจอัตโนมัติจาก PDF)
3. ผลคำนวณเทียบแหล่งอิสระผ่านทุกข้อในตารางตรวจสอบ (ข้อ B) ภายในค่าคลาดที่กำหนด
4. สุ่มสร้างโมเดล 500 แบบ: โปรแกรมไม่ล่ม ไม่มีค่า NaN แรงลงฐานรากเท่ากับน้ำหนักทั้งหมด
5. งานจริงหลังที่ 2 (ไม่ใช่ยโสธร): ผลของโปรแกรมใกล้เคียงรายการคำนวณเดิมของผู้ใช้ และอธิบายจุดที่ต่างได้ทุกจุด
6. ข้อมูลไม่หาย: บันทึกอัตโนมัติ เปิดไฟล์เก่าได้ทุกเวอร์ชัน ย้อนกลับได้
7. ผู้ใช้ตรวจรับ (ทำบ้าน 2 ชั้นใหม่หนึ่งหลังเองตั้งแต่ต้นจนได้ PDF)

## A. ทดสอบหน้าเว็บอัตโนมัติ (E2E, Playwright)
สคริปต์ `cli/e2e/` ขับเบราว์เซอร์จริง บันทึกภาพทุกขั้นไว้ใน `rea-lab\results\` และต่อท้ายใน history.jsonl
- A1 โครงการใหม่ตั้งแต่ศูนย์: กริด → ชั้น → วาดเสา/คาน (รวมคานซอย คานยื่น คานโค้ง) → พื้นแต่ละชนิด → พื้นยื่น → บันได → ผนัง → ราว/น้ำหนักจุด
  → หลังคา → เลือกแรงด้านข้าง → วิเคราะห์ → ออกแบบ → ฐานราก → รายการคำนวณ → ออก PDF
- A2 บันทึกโครงการ → เปิดใหม่ → ผลต้องเหมือนเดิมทุกค่า · เปิดไฟล์รุ่นเก่า (fixtures ทุกเวอร์ชันที่เคยมี)
- A3 ย้อนกลับ / ทำซ้ำ ทุกขั้น (รวมหลังคา) · Ctrl+Z ไม่ซ้ำสองครั้ง
- A4 DXF ส่งออกแล้วนำเข้ากลับ ได้แปลนเดิม
- A5 ขนาดจอ 1366 / 1920 · ธีมสว่าง / มืด · ทุกขั้นไม่มีส่วนล้นจอ ไม่มีตัวหนังสือสีจมพื้น
- A6 ไม่มี error / warning ของ React ใน console ทุกขั้น
- A7 ข้อความในหน้าจอและรายงานเป็นไทย ศัพท์เดียวกันทั้งโปรแกรม (ทำรายการศัพท์กลาง)

## B. ตรวจความถูกต้องทางวิศวกรรม (แหล่งอิสระ)
| ส่วน | แหล่งเทียบ | ค่าคลาด |
|---|---|---|
| คาน พื้น เสา บันได ฐานราก หลังคาเหล็ก | Excel ของผู้ใช้ (รันชุดเดิมทั้งหมดซ้ำ) | ตรงทุกค่า |
| คานต่อเนื่อง โครง 3 มิติ P-Delta คานโค้ง | PyNite (เพิ่มกรณี: คานซอยหลายทอด เสาลอย คานยื่นสองข้าง ฐานผสม) | 0.01 % / P-Delta 0.5 % |
| การถ่ายน้ำหนักพื้น → คาน → เสา → ฐาน | สคริปต์คำนวณมืออิสระ (Python) ของยโสธร 1 แนวเสาทั้งต้น + 1 ฐานราก | 1 % |
| น้ำหนักพื้นสองทาง / ทางเดียว / พื้นสำเร็จ | สูตรมือ (สามเหลี่ยม / คางหมู) ทุกแบบในตาราง | 0.1 % |
| แรงลม แผ่นดินไหว | ตัวอย่างคำนวณในมาตรฐาน มยผ. 1311-50 / 1302-61 (ผู้ใช้ส่งไฟล์มาตรฐาน) | 1 % |
| ชุดผสมแรง | ตรวจรวมแรงด้วยมือ 3 ชุด | ตรง |
| รายการคำนวณ (PDF) | อ่านตัวเลขจาก PDF เทียบผล engine อัตโนมัติ | ตรงทุกค่า |

## C. ความทนทาน
- C1 สุ่มโมเดล 500 แบบ (กริด ชั้น คานซอย คานโค้ง ช่องเปิด บันได) → ไม่ล่ม, ΣRz = น้ำหนักทั้งหมด, ไม่มี NaN, เวลา < 2 วินาที
- C2 ข้อมูลผิด: คานยาว 0, คานซ้อน, คานลอยไม่มีที่รับ, ชั้นว่าง, หน่วยผิด, ไฟล์เสีย → ข้อความเตือนภาษาไทยที่บอกวิธีแก้ ไม่ใช่จอว่าง
- C3 โมเดลใหญ่ 10×10 กริด 4 ชั้น: แก้ไขแล้วผลขึ้นภายใน 2 วินาที (ถ้าช้า → คำนวณใน Web Worker)
